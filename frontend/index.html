Tổng quan Hệ thống & Kiến trúc Database-per-Service

Số liệu thống kê thời gian thực và điểm kết nối kỹ thuật giữa các Microservices.

🗄️ Công cụ kiểm tra Database & API Contract

  • API Gateway (cổng truy cập thống nhất): http://localhost:8080
  • Eureka Discovery Dashboard: http://localhost:8761 — kiểm tra đăng ký của PROFILE-SERVICE, DOCUMENT-SERVICE và API-GATEWAY.
  • Swagger UI (truy cập kỹ thuật trực tiếp): Profile Swagger | Document Swagger
  • Database: PostgreSQL; H2 Console đã tắt. Các API nghiệp vụ từ giao diện sử dụng cổng Gateway 8080.
